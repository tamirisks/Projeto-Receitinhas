# Projeto-Receitinhas

### Status do projeto 
Em desenvolvimento

### Tecnologias aplicadas
Java e banco de dados MySQL.

### Time de desenvolvedores
Tamiris Kuhn de Souza

### Objetivo do software 
Software pensado para em facilitar a vida de pessoas que apreciam a culinária, podendo acessar facilmente novas receitas e ter a oportunidade de ajudar outras pessoas compartilhando suas próprias receitas.

### Funcionalidades do sistema
Cadastro de usuário, cadastro de receitas, categorias das receitas e catálogo de receitas.
